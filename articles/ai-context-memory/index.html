AIが話を忘れるのはなぜ？ コンテキストを「机の広さ」で説明

公開 2026-11-03約1分

長く話していると、AIは前に話したことを忘れたように見えます。原因は、AIが一度に見られる情報の量に限りがあることです。机の広さのたとえで、コンテキストとメモリ機能の仕組みを説明します。

AIが一度に見られる量には、限りがある

AIが一度に見られる情報の量には、限りがあります。この、AIが一度に見られる情報をコンテキストと呼びます。

机の上の紙しか見えない

コンテキストは、机の広さにたとえられます。会話や資料は、机の上に広げた紙です。AIは、机の上にある紙しか見ることができません。

会話が長くなると、机がいっぱいになります。すると、古い紙が机から押し出されたり、要約されたりします。これが、AIが話を忘れたように見える理由です。

チャットが変わると、机はまっさらになる

AIは、会話が終わるたびに記憶が消えるのが基本です。新しいチャットは、まっさらな机から始まります。

最近のAIにあるメモリ機能は、大事なことをメモしておき、次の会話の机にあらかじめ置いておく仕組みです。

長い会話でおかしくなったときは

長いチャットで答えがおかしくなってきたら、ここまでの要点をAIにまとめてもらい、新しいチャットに貼る方法があります。きれいな机で、続きから話せます。

AIの記憶力は、頭の良さではなく、机の広さで決まります。AIが知らないことをもっともらしく書いてしまう理由は、AIはなぜ嘘をつく？で扱っています。
